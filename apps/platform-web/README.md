# zm-os 웹 호스트

대상: 구현 담당자와 로컬 시험 사용자. 소유자: 프로젝트 소유자. 검토일: 2026-11-01.

React·Vite 기반 Store·내 앱·개발자·운영자 화면이다. 기존 `apps/web`의 단일 사용자 데스크톱과 실행 명령을 구분한다. 정책 근거는 ADR-0042와 zm-docs의 확정 요구사항이다.

## 실행

1. 저장소 루트의 로컬 시험 환경 절차로 PostgreSQL·API·worker·자산 서버를 준비한다.
2. `pnpm install` 후 `pnpm --filter @zm/platform-web dev`를 실행한다.
3. **`http://localhost:4300`**으로 접속한다. `127.0.0.1`은 같은 기기여도 다른 origin이므로 API의 `WEB_ORIGIN`과 일치하지 않으면 변경 요청이 거부된다.
4. Store 목록은 공개다. 로컬 시험 인증이 켜져 있을 때만 로그인 화면에 **모의 로그인**을 표시한다. 모의 로그인은 실제 Google·GitHub 인증을 대신 검증한 것이 아니다.
5. 자기 실행 프로세스를 중지하면 개발 서버가 종료된다. 사용자 데이터나 공용 DB를 자동 초기화하지 않는다.

## 동작

- Store 검색·분류·상세, 로그인 후 내 앱 추가·제거, 앱 신고.
- 첫 실행 전에 앱별 이용 안내·동의. 동의 철회와 현재 기기의 앱 데이터 삭제는 별도 확인.
- 격리 iframe의 전체 화면 실행, SDK 연결, 연결 실패 안내, 5초 간격 권한 확인과 서버 거부 시 종료. 오프라인에서 즉시 중지 신호를 받는다고 보장하지 않는다.
- 개발자 신청·재신청, 앱 등록·ZIP 업로드·검수 제출·승인 판 공개·공개 중단, 서버 자격·종료 요청·외부 데이터 삭제 결과.
- 운영자 신청·버전 검수, 앱 일반/긴급 중지, 사용자 이용 정지, 개발자 승인 취소, 비공개 신고 처리.
- 로그인 연결·해제·재인증, 탈퇴 전 조회 링크 준비와 보관 확인, 탈퇴 후 최소 삭제 상태 조회.
- 소유자·운영자의 비공개 검수 실행은 별도 동의를 받고 일반 실행 데이터와 구분한다.

실제 권한 판단은 API가 수행한다. 버튼 비활성화가 접근 제어를 대신하지 않는다. 비밀 값은 번들·콘솔 로그·일반 저장소에 기록하지 않는다.

## 검증

```text
pnpm --filter @zm/platform-web type-check
pnpm --filter @zm/platform-web build
pnpm --filter @zm/platform-web test:e2e
node apps/platform-web/e2e/withdrawal.mjs
```

E2E는 실행 중인 전용 로컬 시험 환경과 `ZM_TEST_AUTH=1`이 필요하다. 기본 Chromium 채널은 설치된 Edge다. `PLAYWRIGHT_CHANNEL`로 바꿀 수 있다. 시험은 owner 모의 계정으로 고유 이름 앱을 등록하므로 실제 사용자 데이터 환경에서 실행하지 않는다. DB 초기화는 하지 않으며 마지막에 자기 시험 앱을 긴급 중지하고 내 앱 목록에서 제거한다. 산출물·실패 화면은 Git에서 제외한 `e2e-out/`에 남는다.

관찰 범위는 연령 확인 전 버튼 차단, 개발자 신청·승인, 독립 CLI로 만든 번들의 업로드·검증·검수·공개, 미공개 판의 동의·검수용 실행과 저장 분리, 첫 동의·iframe 격리·SDK 저장·재실행 복원, 일반/긴급 중지, 중지된 내 앱 목록 유지·제거, 모바일 폭의 넘침이다. 모든 제품 기능을 포괄하는 인수 시험은 아니다. 실제 OAuth와 Android 실행은 별도다.

`withdrawal.mjs`는 전용 시험 환경의 bob·GitHub 모의 계정을 탈퇴시키고 새로 가입한다. 미리 받은 조회 링크의 보관 확인, 탈퇴가 서버에서 확정된 뒤 응답이 유실된 경우의 상태 조회, 같은 제공자 재가입 시 새 계정 발급을 확인한다. 비밀 링크를 로그에 출력하지 않는다. 다른 시험이 같은 계정을 사용 중이면 동시에 실행하지 않는다.

실패하면 `result.json`과 실패 화면을 확인하고 해당 상태 전이·API 응답을 재현한다. 실패를 숨기기 위해 서버 권한·CSP·sandbox를 완화하지 않는다. 실행 중인 다른 세션의 시험 데이터를 초기화하지 않는다.
