# ADR-0046 — 앱별 개인 서버 저장과 메모 앱

상태: accepted. 대상: 플랫폼·SDK·앱 개발자. 검토일: 2026-11-05.
제품 결정은 zm-docs의 DEC-0175다. ADR-0042의 로컬 전용 SDK 저장 범위를 확장하며 개발자 외부 서버 운영 정책은 유지한다.

## 저장 경계

브라우저 iframe → MessagePort SDK → 웹 호스트 → NestJS API → PostgreSQL 순서로 호출한다. 앱에는 플랫폼 쿠키·DB 접속 정보·다른 앱의 식별자를 전달하지 않는다. Google Drive 연동이 아니다.

새 `cloud-storage` 권한을 매니페스트에 선언하고 새 버전 검수·공개·사용자 재동의를 거친다. 모든 호출에서 로그인·실행 세션·현재 동의·계정 정지·긴급 중지를 재확인한다. 일반 중지는 기존 실행을 허용한다. 사용자·앱·검수 영역은 세션의 app_user_id로 정하며 호출자가 입력할 수 없다.

`cloud_spaces`는 저장 세대와 용량, `cloud_records`는 JSON 값과 수정 번호·삭제 표식, `cloud_receipts`는 재시도 결과를 보관한다. 일반 이용과 검수는 별도 app_users 행으로 분리한다. DB RLS나 종단간 암호화를 구현한 것은 아니다. 개발자·운영자 콘솔에 이용자 메모 본문 조회 기능을 제공하지 않는다.

## 정합성과 제한

- SDK `cloud.get / put / remove / list`는 실행 권한을 통해 호출한다. HTTP 계약은 [API 문서](../01-architecture/platform-api-trial.md)를 따른다.
- 쓰기는 generation·expectedRevision·requestId를 요구한다. 오래된 수정 번호는 409로 거부한다. 값·수정 번호·용량·재시도 결과를 한 트랜잭션에서 확정한다.
- 동일 요청의 재시도는 24시간 내 원래 결과 메타데이터를 반환한다. 다른 내용에 같은 ID를 재사용하면 거부한다. 결과에 본문을 복제하지 않는다. 만료 뒤에도 이전 수정 번호로 덮어쓰기는 할 수 없다.
- 항목 삭제는 본문을 지우고 수정 번호와 삭제 표식을 남긴다. 전체 삭제는 세대를 교체하고 기록·재시도 결과를 제거하며 해당 실행을 철회한다. 이후 이전 세대·세션의 쓰기를 거부한다.
- 시험값: 영역 5 MiB, JSON 직렬화 값과 키 합계 32 KiB/항목, 삭제 표식 포함 500개 키, 분당 성공 요청 120회, 재시도 기록 5,000개. NUL·단독 surrogate는 거부한다. 실패 요청의 비용 제한·분산 제한은 공개 운영 전 보강 대상이다.
- 현재 API의 전역 advisory lock을 유지한다. 대규모 동시 사용자 처리 성능을 검증한 설계가 아니다.

## 메모 앱과 삭제

`examples/local-notes` 1.1.0은 서버 메모를 사용한다. 서버 저장이 확정된 뒤 성공을 표시한다. 응답 유실은 동일 요청으로 재확인한다. 다른 기기의 수정과 충돌하면 양쪽 내용을 보여 주고 직접 합치거나 서버 내용을 선택하게 한다. 편집 중 입력은 자동 조회로 덮어쓰지 않는다.

기존 IndexedDB의 note는 안내 후 편집창으로 가져오고 사용자가 저장할 때만 서버에 복사한다. 원본은 자동 삭제하지 않는다. 미저장 초안은 가능한 경우 현재 기기에 별도 보관하며 명시적으로 복원한다. 초안은 기기 간 동기화·서버 백업의 대상이 아니다.

내 앱 목록 제거·동의 철회는 데이터를 지우지 않는다. 내 계정의 이용 앱 관리에서 서버 데이터 전체 삭제와 현재 기기 데이터 삭제를 각각 제공한다. 계정 탈퇴 worker는 일반·검수 영역 모두의 서버 데이터를 지운다. 외부 앱 DB·이미 내려받은 사본·운영 백업 삭제와 구분한다.

## 확인과 운영 경계

독립 시험 DB에서 `pnpm test`, `pnpm test:web-flows`, `pnpm platform:recovery`를 사용한다. cloud API 시험은 프로세스 재실행·계정/앱/검수 격리·동시 쓰기·재시도·삭제·탈퇴를 다룬다. cloud-notes 브라우저 시험은 실제 번들의 이전·충돌·응답 유실과 좁은 화면을 다룬다. 결과는 [로컬 시험 안내](../01-architecture/platform-trial.md)에 기록한다.

웹을 먼저 제공하며 Android·공개 배포·유료 운영은 보류한다. 서로 다른 PC는 같은 접근 가능한 서버 주소를 사용해야 한다. 각 PC의 localhost는 같은 서버가 아니다. CLI 단독 시험 호스트는 서버 저장을 제공하지 않으므로 전체 플랫폼에서 실행해야 한다. 운영 백업 보관·접근 통제·복구 목표·관측성·부하 시험은 공개 운영 전에 별도로 확정한다.
