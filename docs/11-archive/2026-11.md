### 구현

- NestJS·PostgreSQL: 계정·로그인 연결/해제·개발자 신청/승인/취소·앱 소유권·불변 버전·검수·공개·중지·신고·동의·실행·외부 서버 인증·탈퇴/삭제 상태.
- 별도 worker: ZIP 검사·지문·파일 준비·재시도·lease revision·프로필 정리. 파일 준비와 공개 포인터 변경을 구분했다.
- React/Vite: Store·검색·분류·내 앱·단일 앱 실행, 개발자·운영자 콘솔, 비공개 검수, 계정·탈퇴 흐름.
- SDK·CLI: 앱 생성/빌드/검사/패킹/독립 시험 호스트. MessagePort, 사용자·앱별 로컬 저장, 앱별 식별자, 외부 인증 코드.
- 두 예제: 서버 없는 메모와 개발자 소유 SQLite 서버를 사용하는 메모. 플랫폼은 앱 서버 코드를 실행하거나 업무 DB를 생성하지 않는다.
- Android: Expo/WebView 호스트·시스템 브라우저 인증·현재 계정 결합·단회 복귀, 네이티브 툴바 시작과 nonce 검사. WebView의 프레임 정보 전달과 탐색 무응답 차단 패치를 적용했다.
- 초기 운영자: 실제 인증된 기존 계정에 로컬 관리 CLI로 권한 부여/회수. 공개 가입 경로와 분리했다.

전체 시험은 12개 작업을 실제 수행했고 API 통합 시험은 Turbo 캐시를 끄도록 설정했다. 실제 Google·GitHub 제공자 URL을 따라간 인증 시험은 하지 않았다. 일부 native 인증 시작 시험은 시험용 제공자 설정에서 리다이렉트와 DB 결합만 확인했다.

worker 실패 시험은 실제 DB·파일에 대해 파일 준비 뒤 DB 반영 전 처리를 대기시켜 lease 만료→다른 worker 성공→이전 worker 재개를 확인했다. OS 프로세스를 강제로 종료한 시험은 아니다. 탈퇴의 HTTP 시험은 응답 본문을 사용하지 않고 선행 보관한 자격으로 조회했으며, 브라우저 시험은 서버 응답을 의도적으로 차단했다. 임의의 운영 네트워크 장애 전체를 검증했다는 뜻은 아니다.

### 검토에서 수정한 문제

- 개발자 승인 취소 후 공개 중단·종료 요청까지 막히던 권한 검사.
- 준비 파일은 존재하지만 DB 반영 전 종료된 worker의 재시도 충돌과 소진 lease 정체.
- DB 실패·중복 제출 뒤 남는 업로드 파일, 번들 검사와 자산 경로/MIME의 불일치.
- 중지 앱이 내 앱 목록에서 사라지는 문제, 정지 해제 뒤 기존 웹·미사용 native 인증 자격이 부활하는 문제.
- 제공자 연결 해제·원 세션 로그아웃 후 native 교환 재사용, 현재 기기의 계정 전환 후 이전 실행 잔존.
- 탈퇴 응답 유실 시 조회 자격을 잃는 문제. 링크를 탈퇴 전에 발급해 보관하도록 변경했다.
- 검수용 사용자·저장의 일반 실행 혼합. 동일 외부 앱의 검수/일반 식별자 두 개에 대한 탈퇴 삭제 요청도 회귀 시험에 포함했다.
- 모바일 WebView 이벤트의 `isTopFrame` 누락, 탐색 검사 무응답 시 허용, 로컬 HTTP 개발 연결 설정 누락.

주세션 자체 검토와 별도 설계 담당의 정적 재검토를 구분했다. 최종 독립 정적 검토는 추가로 확정한 중대 실패가 없다고 보고했다. 실제 기기·제공자·운영 환경의 검증 통과 판정은 아니다.

### 재현과 남은 일

브라우저 재현은 `apps/platform-web/e2e/local-trial.mjs`, `apps/platform-web/e2e/withdrawal.mjs`, `packages/cli/e2e/dev-host.mjs`, `packages/cli/e2e/platform-external.mjs`다. 결과 JSON·스크린샷은 각 `e2e-out/`에 저장하며 Git에 포함하지 않는다. 기록에는 비밀 값이나 사용자 데이터를 옮기지 않았다.

실제 Google·GitHub 앱 설정과 Android SDK·기기 준비가 필요하다. 소유자에게 기존 OAuth 등록 여부와 설정 파일 위치를 물었고 이번 기록 시점에는 답을 받지 못했다. 자격증명 값을 대화에 붙여 넣도록 요구하지 않았다. 실제 OAuth·계정 연결/재인증·Android Java 빌드·설치·복귀·브리지/탐색/연결 단절 시험 전에는 첫 개발 단계 완료로 판정하지 않는다.

유료 자원·일반 사용자 공개 배포·운영 보관 기간·클라우드 공급자·부하 목표는 이번 범위에 포함하지 않았다. 초기 임시 앱 폴더 하나의 재귀 삭제는 자동 승인 검토가 `blocked by policy`로 거부하여 남았다. 세부 사유는 없었으며 비밀정보 없는 생성 앱과 ZIP만 있다. 경로는 로컬 세션 메모리에 기록하고 공개 문서에는 넣지 않는다.
