# 나의 메모

대상: 앱 개발자. 생성일: 2026-11-01

플랫폼 저장소를 수정하지 않고 이 디렉터리에서 앱을 개발합니다. `manifest.json`의 `appId`는 개발자 콘솔에서 등록한 앱 ID로 맞추세요.

1. `zm-app build .`로 웹 산출물을 만듭니다.
2. `zm-app dev .`로 사용자 변경·일반 중지·긴급 중지·권한 실패를 시험합니다.
3. `zm-app pack . --out app.zip` 후 개발자 콘솔에 제출합니다.

검사는 권한 선언과 구조를 확인하며 코드 안전성이나 운영자 검수를 대체하지 않습니다. 실패 시 오류를 수정한 뒤 재실행하세요. 비밀정보는 앱 코드에 넣지 마세요.
