# 2026-08 작업 로그

## 2026-08-04 — 아키텍처 전면 검토 반영 (G0~G3)

유연성·확장성·표준성 관점의 전면 검토에서 56건(high 11 / medium 28 / low 17)을 확정하고
의존 순서대로 G0~G3을 반영했다. G4(P4)·G5(P5)는 별도 세션 대상으로 남겼다.

### 수정한 실제 버그

| 대상 | 증상 | 원인 |
|---|---|---|
| DSK-04 레이아웃 복원 | 저장은 되나 새로고침 후 창이 하나도 복원되지 않음 | 레이아웃과 설치 목록이 별개 IDB 로드라 순서 미보장. 레이아웃이 먼저 오면 APP-04 자동 닫기가 "미설치"로 오판 |
| 창 열기 미저장 | 창을 열고 움직이지 않은 채 새로고침하면 유실 | `dispatch` 직후 동기 저장이 이전 상태를 읽음. 첫 창이면 빈 배열이라 early return |
| DSK-05 설정 상호 삭제 | 배경만 바꿔도 저장된 themeMode가 기본값으로 덮어써짐 | `loadDesktopSettings`가 에러를 삼켜 `hydrationFailed`가 항상 false + setter가 나머지 필드를 손으로 재조립 |
| `compareSemver` | `"1"`과 `"1.0.5"`를 동일로 판정 | `undefined`는 `>`도 `<`도 false |
| 어댑터 정책 | `local-memory` 선언이 OPFS 영구 저장으로 뒤집힘 | 3값을 2값으로 접어 리졸버에 전달 |
| 스토어 아이콘 | 화면 우측 밖으로 50px 이탈 | `DesktopIcon`이 무조건 absolute라 부모 `<Link>`가 0×0으로 접힘 |

### 구조 개선

- **새 namespace 추가 비용**: 4파일 9곳 → 레지스트리 1항목 + `NS_*` 1줄.
  `DB_VERSION`·idb 스키마 타입·upgrade objectStore 생성을 전부 파생 (ARCH-05)
- **계층 방향 정상화**: `lib/storage`에서 표현 로직 분리 →
  `components/desktop/{icon-grid,wallpaper-presets}.ts`. `desktop-icons.ts` 197줄 → 33줄
- **쓰기 가드 일원화**: `usePersistence.writable` (PROD-06). 세 소비자에 복제돼 있었고 하나가 빠뜨려 버그가 났다
- **ADR-0040**: `contentRef`에 `inline-html` variant + `normalizeAppRecord` — P5 데이터 모델 블로커 해소

### 안전망

- `pnpm lint` 복구 (TECH-11). `next lint`는 Next 16에서 제거됨. error 0 / warning 23
- `noUncheckedIndexedAccess` 전 패키지 적용 (TECH-12), 테스트도 type-check 대상
- 테스트 133 → 185: `host.ts` 보안 게이트 12 · `windowReducer` · CSP · 아이콘 격자 · AppRecord 승격 13

### 신규 기능

- **DSK-06** 아이콘 드래그 이동 + 격자 정렬. Pointer Events, 4px 임계값, 100×100 스냅,
  겹침 회피(인접 빈 셀 탐색), 영역 밖 재클램프, 자동 정렬·초기화 컨텍스트 메뉴

### 미해결로 넘긴 것

- 잘못된 레코드 1건이 스토어 페이지 전체를 죽인다 (`defaultWidth` 크래시).
  레거시 `user-apps.ts` 경로라 ADR-0040 정규화를 타지 않는다 — **P5 배선이 이를 "건너뛰기"로 바꾼다**
- `system` namespace는 `DB_VERSION` 5까지 올려 생성했으나 읽기·쓰기 코드 0건. LocalAuth(P4)가 유일한 소비자
- 배경 프리셋 버튼에 접근 가능한 이름 없음 (a11y 경고로 노출)
- lint warning 23건: 미사용 변수 5 · `@zm/storage` import 5(P5 대상) · `no-img-element` 2 등
